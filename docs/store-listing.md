## ストアの掲載情報

### 言語

日本語(既定)。他言語のローカライズは当面追加しない。

### アイテム名(最大 75 文字)

```
numenumd — ローカルの Markdown をそのまま書けるエディタ
```

> `manifest.json` の `name`(`numenumd`)とは別枠で、ストア上の表示名として
> 使われる。`manifest` 側の `name` は 45 文字までなので短いままにしてある。

### 概要 / Summary(最大 132 文字)

```
ローカルの .md ファイルを Chrome で開くだけで、Notion 風の WYSIWYG エディタに。保存すると整形済み Markdown として同じファイルに書き戻します。
```

### 詳細な説明 / Description

````
numenumd は、パソコンの中にある Markdown ファイルを「開いたその場で」書けるようにする Chrome 拡張機能です。

file:// で .md ファイルを開くと、Chrome が普段表示するプレーンテキストの代わりに、Notion 風の WYSIWYG エディタが立ち上がります。書き終えて Cmd+S(Windows/Linux では Ctrl+S)を押すと、Prettier で整形された Markdown として、開いていたファイルそのものに書き戻されます。

■ サーバーもアカウントも不要
numenumd はネットワーク通信を一切行いません。ログインも同期もなく、あなたのノートがどこかに送られることはありません。状態はブラウザのタブと .md ファイルの中にしかありません。

■ 書きながら整う
- 「# 」「- 」「1. 」「> 」「```」を打つと、その場で見出し・リスト・引用・コードブロックに変わります
- 「/」でスラッシュメニューが開きます(Heading 1〜3、箇条書き、番号付きリスト、To-do リスト、引用、コードブロック、テーブル、数式ブロック。日本語キーワードでも絞り込めます)
- Cmd+B(太字)、Cmd+I(斜体)、Cmd+E(インラインコード)、Cmd+K(リンク)、Cmd+Alt+1〜6(見出し)

■ 数式は KaTeX でそのまま
インライン数式 $…$ とブロック数式 $$…$$ を KaTeX で描画します。描画された数式はクリックすればその場で LaTeX の編集に戻れ、Escape または Cmd+Enter で確定します。地の文に出てくる通貨記号の $ は、Pandoc 方式のペア判定によって数式と区別されます。

■ テーブルもそのまま編集できる
GFM のパイプテーブルは罫線付きの表として描画され、そのまま編集できます。表にカーソルを置くと現れる「+」で行と列を足し、上端・左端のグリップをクリックして選ぶと行や列ごと削除できます。Tab でセルを移動し、最後のセルで Tab を押すと行が増えます。「:---:」などの揃え指定も保存時にそのまま残ります。

■ あなたの Markdown を壊さない
生 HTML、リンク参照定義など WYSIWYG に変換できない記法は、内容を一切変更せずに生の Markdown ブロックとして保全して表示します。テーブルも、GFM の仕様上そのまま往復できないもの(ヘッダの列数より多くセルを書いている行があるもの)は、勝手に整えずに生のまま保全します。先頭の frontmatter(--- で囲んだ YAML)も折りたたんで表示し、保存時は整形の対象外として一字一句そのまま書き戻します。

■ ダークモード対応
ヘッダ右上のボタンで Auto(OS 設定に追従)/ Light / Dark を切り替えられます。

■ 使い始める前に
numenumd はローカルファイル上で動く拡張機能のため、インストール後に一度だけ設定が必要です。

1. chrome://extensions を開く
2. numenumd のカードで「詳細」を開く
3. 「ファイルの URL へのアクセスを許可する」を ON にする

この設定を ON にしない限り、numenumd はいかなるファイルにもアクセスできません。

■ 対象ファイル
拡張子が .md のローカルファイルのみです。.md 以外のファイルや、http/https のウェブページでは一切動作しません。

■ オープンソース
https://github.com/tomoyahiroe/numenumd
````

## プライバシー タブ

### 単一用途の説明(Single purpose)

```
ローカルディスク上の Markdown(.md)ファイルを、ブラウザ上で編集して同じファイルに保存できるようにすること。numenumd の機能はこの一点のみで、他の目的の処理は行いません。
```

### 権限の正当な理由

**ホスト権限 `file:///*`**

```
numenumd は file:// で開かれた .md ファイルのページに content script を挿入し、Chrome が既定で表示するプレーンテキストを WYSIWYG エディタに置き換えます。この処理には、対象ページ(ローカルファイル)への読み取りアクセスが必要です。include_globs により対象を *.md に限定しており、.md 以外の file:// ページには一切介入しません。http/https のウェブサイトに対する権限は要求していません。

なお、この権限は Chrome の既定では無効です。利用者が chrome://extensions で「ファイルの URL へのアクセスを許可する」を明示的に ON にしない限り、拡張機能はいかなるファイルにもアクセスできません。
```

> `permissions` 配列は空(宣言なし)、`host_permissions` も宣言していないため、
> 正当化が必要なのは content script の `matches` に対応するこの 1 件だけ。

### リモートコードの使用

**いいえ、リモートコードは使用していません。**

```
すべての実行コードは拡張機能のパッケージに同梱されています。eval や外部スクリプトの読み込みは行いません。
```

### データ使用に関する申告

収集するデータは **ありません**。以下のすべてのカテゴリで「収集しない」を選択する。

| カテゴリ                   | 回答       |
| -------------------------- | ---------- |
| 個人情報                   | 収集しない |
| 健康情報                   | 収集しない |
| 金融情報および支払い情報   | 収集しない |
| 認証情報                   | 収集しない |
| 個人的なコミュニケーション | 収集しない |
| 位置情報                   | 収集しない |
| ウェブ履歴                 | 収集しない |
| ユーザーの操作             | 収集しない |
| ウェブサイトのコンテンツ   | 収集しない |

> 判断根拠: numenumd はファイルの内容をタブ内で読み取って表示・編集するが、
> それを外部へ送信も保存もしない。ウェブストアの「収集(collect)」は
> 「拡張機能の外へ転送すること」を指すため、いずれも「収集しない」が正しい。

### 3 つの証明(チェックボックス)

すべてにチェックを入れる。いずれも事実と一致している。

- ユーザーデータを、承認された用途以外に使用または転送していません
- ユーザーデータを、信用力の判断や融資目的で第三者に販売または転送していません
- ユーザーデータを、承認された用途以外の目的で使用または転送していません
