# MTG: Markdown 表(GFM パイプテーブル)対応

日付: 2026-08-09

## 前提(事前合意)

- `@tiptap/extension-table` を入れて WYSIWYG で編集可能にする。
- 往復で情報が落ちる表は従来どおり `rawBlock` で verbatim 保全するハイブリッド。
- spec / plan を先に更新してから実装する。

## 決定

- 編集可能にする表の線引きは「情報が落ちるかどうか」だけで決める。ヘッダ列数を
  超えるセルを持つ行が1行でもある表は `rawBlock` のまま。それ以外は table ノードへ
  変換する。セル数が足りない行の空セル補完は許容する。
- 揃え記法(`:---` / `:---:` / `---:`)は列の属性として往復で保持する。
- セル結合は編集機能として提供しない(`mergeCells` を UI に出さない)。GFM の
  パイプテーブルにセル結合の記法自体が存在しないため。HTML テーブルの
  `rowspan` / `colspan` は従来どおり `rawBlock` で生のまま表示・保存される。
- セル内容は単一段落に制限する(tiptap 既定の `block+` を使わない)。GFM の
  セルにはインラインしか書けないため、リスト・コードブロック・複数段落を
  作れてしまうと保存時に必ず壊れる。
- 保存時の桁揃えは既存の Prettier 整形にそのまま任せる。シリアライザは最小形
  (`| a | b |`)を出力すればよく、新たな決め事はない。
- セル内の Shift+Enter(hardBreak)は無効にする。GFM のセルは改行を表現できず、
  既定のシリアライズだと `\` が入って表が壊れるため。
- 行/列の追加 UI は、表にカーソルがある間だけ右端と下端に出る `+` ボタン
  (Notion と同じ形)。加えて Tab でのセル移動と、最終セルでの Tab による行追加。
- 行/列の削除 UI は、表の上端と左端に出る細いグリップ帯。クリックでその行/列を
  選択(ProseMirror の `CellSelection`)し、選択中の Backspace で削除する。

- リリース運用。ストア公開 PR #7 を先にマージし、表対応は `main` から
  `feat/table` を切って 0.3.0 の別 PR として出す。

## 保留

- 表内でインライン数式(`$…$`)の KaTeX 装飾が効くか。Mathematics 拡張と
  table のノードビューの相互作用は実装時に実機確認する。
- 画面幅を超える広い表の扱い(横スクロールさせるか、セル幅を詰めるか)。
  CSS の詳細は実装時に決める。
- 表内での vim モード(Phase 2)の挙動。Phase 2 実装時に改めて扱う。
