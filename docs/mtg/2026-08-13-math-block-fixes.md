# math block の削除手段と1行 `$$…$$` の扱い

日付: 2026-08-13

## 背景(バグ報告)

1. math block を削除する方法がない
2. `$$Y = X + a$$` がレンダリングされないことがある(条件が不明)

調査結果:

- **2 の条件は「`$$` と `$$` が同じ行にあるか」だった。** 1行 `$$…$$` はブロック側
  (`parse.ts` の `mathBlockRule` が開き行の残りを空白のみに限定)にもインライン側
  (`math-spans.ts` の `matchMathSpanAt` が `$$` 隣接を除外)にも拾われず、素の
  テキストとして落ちる。複数行 `$$`⏎…⏎`$$` は正しく mathBlock になる。
  エディタ上で直接打った場合も入力ルールが `/^\$\$\s$/` のみのため同じ。
- **1 の原因は NodeView の `stopEvent: () => true`。** ProseMirror が math block 上の
  mousedown/click を受け取れず、マウスでノードを選択する手段が存在しない。さらに
  textarea を空にして抜けると、空の mathBlock が高さ 16px の不可視な帯として残る
  (`.numenumd-math-block` は padding のみで枠線も文字もない)。
  キーボード(直後の段落で Backspace)だけは動くが、それを示す表示がない。

## 決定

- **1行 `$$…$$` はブロック数式として取り込み、保存時も1行のまま書き戻す。**
  Prettier は `$$Y = X + a$$` を段落として扱いこの行に触らない(確認済み)ため、
  3行に正規化すると numenumd だけが起こす差分になってしまう。
  エディタ上で新規作成した math block は従来どおり3行で書き出す。
- **削除手段は「編集モードで中身を空にして Backspace」。** ブロックごと消える。
  ボタンやハンドルなどの新しい UI は足さず、マウスだけで完結させる。
- **空の math block は自動削除しない。** 元から `$$`⏎⏎`$$` を含むファイルがありうる
  ため(「ユーザーの Markdown を絶対に失わない」原則)。代わりに薄いプレースホルダを
  表示し、不可視の帯として残らないようにする。
- **今回のスコープは math block のみ。** rawBlock と frontmatter も同じ
  `stopEvent: () => true` で同じ削除しにくさを持つが、見た目があるぶん緊急度が
  低いため今回は触らない。

## 追加決定(独立レビュー後、2026-08-13)

- **`listItem` シリアライザの空段落問題を同時に直す。** レビューで
  `- $$a = b$$` が「開いて保存するだけ」でリストごと壊れることが判明した。
  `listItem` のスキーマは `paragraph block*` なので、段落以外のブロックで
  始まる項目をパースすると `createAndFill` が空の `paragraph` を先頭へ挿入し、
  それを書き出すと「空行で始まるリスト項目」= 空の項目になって後続ブロックが
  項目の外へ飛び出す。
  1行 `$$…$$` を取り込む決定を「リストの中では取り込まない」と狭めるより、
  シリアライザ側を直すほうが決定に忠実だと判断した(MTG のスコープからは
  外れるが、狭めるのも決定の変更にあたるため)。
  なお ` - ```code``` ` / `- > quote` / リスト内の3行数式は**同じ原因で
  main の時点から壊れている**ので、これらも同時に直る。

## 保留

- rawBlock / frontmatter の削除手段(math block と同じ根本原因)。今回は対象外。
- リスト項目・テーブルセル・見出しの中で `$$x$$` と**打った**場合、その行の
  ブロックごと mathBlock に置き換わる(既存の `$$ ` 入力ルールと `$$`+Enter が
  main の時点で同じ壊し方をするため、新しい退行ではない)。別途扱う。
- `$$ Y = X + a $$` は `$$Y = X + a$$` に詰められる(内側の余白は落ちる)。
  内容は失われないが、Prettier が触らない行なので numenumd だけが起こす差分に
  なる。既知の逸脱として受け入れる。
- 文中の `foo $$x$$ bar`(行の途中に現れる display math)。今回は行頭 `$$` で
  始まる行だけを対象にする。
